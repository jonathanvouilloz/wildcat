## Structure H2/H3 (Module A — réponse honnête + cadrage)

### Intro (pas de H2 — prose directe)
Keywords: `do you need a dtv visa agent`, `dtv visa agent cost`
Contenu : Répondre vite : pour la plupart des candidats avec un dossier complet et cohérent, non, un agent n'est pas nécessaire. Poser le fait central : les agents facturent 30 000 à 80 000 THB (matière Reddit thème 5, reformulée en attribution de catégorie) pour un process que la majorité des candidats peuvent faire seuls. Meaw parle en première personne : elle guide les candidats gratuitement via WhatsApp depuis des années et voit rarement un cas qui nécessite vraiment un agent payant.

### H2: What does a DTV visa agent actually do?
Keywords: `dtv visa application`
Contenu : Décomposer ce qu'un agent facture réellement : remplissage du formulaire en ligne, vérification des documents, parfois traduction, parfois accompagnement au dépôt. Rappeler (fact-check #11) que le dépôt se fait uniquement depuis l'étranger, sur le portail officiel [thaievisa.go.th] — un agent n'a pas d'accès privilégié à l'ambassade ni de "voie rapide" garantie.

### H2: What DTV visa agents actually cost
Keywords: `dtv visa agent cost`, `dtv visa agent price thailand`
Contenu : Fourchette observée 30 000-80 000 THB (reformulation attribution de catégorie de la matière Reddit thème 5 : "some applicants report agent fees in the 30,000 to 80,000 THB range"). Comparer au frais d'ambassade officiel de 10 000 THB (fact-check #7) : l'agent peut représenter 3 à 8 fois le frais officiel lui-même. Pas de jugement moralisateur, juste le chiffre en perspective.

### H2: Can you apply for the DTV yourself?
Keywords: `dtv visa without agent`, `can i apply for dtv myself`
Contenu : Oui, pour un dossier standard (fonds clairs sur un compte personnel, activité soft power documentée, pas de situation légale compliquée), le process est direct. Lister les 3-4 étapes clés en une phrase chacune, avec renvoi vers [le guide complet pas-à-pas](/dtv-visa/how-to-apply) pour le détail. Rappeler le temps de traitement réaliste (5-15 jours ouvrés, jusqu'à 3-6 semaines en haute saison, fact-check #10).

### H2: When does hiring an agent actually make sense?
Keywords: `when do you need a dtv agent`
Contenu : Cadrer honnêtement les cas où un agent se justifie vraiment : situation d'immigration compliquée dans un pays tiers, dossier de fonds complexe (multi-comptes, fonds récents), barrière de langue forte sans accès à de l'aide gratuite, ou simplement manque de temps/envie de gérer soi-même. Ne pas dénigrer les agents par principe : reconnaître que certains candidats préfèrent payer pour la tranquillité d'esprit, tant que le prix est clair en amont.

### H2: Signals of a fair agent vs one to avoid
Keywords: `dtv agent scam`
Contenu : Signaux concrets et neutres : prix clair avant paiement, pas de promesse d'approbation garantie (aucun agent ne contrôle la décision de l'ambassade), politique de remboursement claire en cas de refus (renvoi vers [l'article dédié](/blog/dtv-visa-refund-if-rejected)), et transparence sur ce qui est réellement inclus dans le prix.

### H2: FAQ
Keywords: `do you need a dtv visa agent`, `dtv agent worth it`
Contenu : 4 questions PAA-style :
1. How much does a DTV visa agent typically cost?
2. Can I apply for the DTV visa without any help?
3. Does hiring an agent guarantee my DTV visa gets approved?
4. What should I ask a DTV agent before paying them?
Pas de JSON-LD FAQPage.

### Conclusion (pas de H2 — contrat de fin article)
Contenu : Récap honnête en 2-3 phrases (la plupart n'ont pas besoin d'agent, le process est direct pour un dossier clair, et Wildcat aide gratuitement via WhatsApp pour la partie training). CTA unique final : `/contact?intent=dtv`.
